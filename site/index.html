Calcula Lab

No ar

Calculadoras que mostram a conta, não só o resultado.

Calculadoras práticas para dois nichos: homelab e confeitaria. Você coloca os seus números e cada calculadora mostra a fórmula e as premissas usadas. Sem cadastro, sem cookies e sem nada para vender.

  • Homelab: custo de energia 24 h, dimensionamento de nobreak, capacidade útil de RAID/RAIDZ/SHR, disco para câmeras (DVR/NVR), servidor em casa vs. nuvem
  • Confeitaria: preço de bolo e doce (custo por grama, mão de obra e margem)

Ruiz App Store

Open source

Loja de apps para o Umbrel, o sistema de servidor caseiro.

Uma loja comunitária para o umbrelOS com apps que desenvolvi. Basta adicionar a URL do repositório no Umbrel para instalar qualquer um deles com um clique.

  • Claude Server: roda o Claude Code no servidor e controla tudo pelo navegador, de qualquer dispositivo. As sessões continuam rodando quando você desconecta, como um tmux na web
  • Gitea Runner: runner self-hosted de CI/CD para o Gitea Actions, com várias instâncias, start/stop e logs ao vivo pela interface web
